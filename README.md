# SellPilot — Small Seller Toolkit\n\nThis repository has been repurposed from the previous AniGlow prototype into SellPilot. The existing dark-purple, pink-accented visual identity, card styling, responsive layout, section navigation and modal interaction pattern have been retained and adapted for small business use.\n\n## Target customer\nSmall online sellers and home-based businesses: flower and gift sellers, clothing sellers, handmade-product businesses, hamper makers and social-commerce shops.\n\n## Prototype functionality\n- Responsive SellPilot landing page, features and proposed pricing.\n- Searchable and filterable sample product catalogue.\n- Product detail modal.\n- Demo business workspace: Overview, Products, Orders and Invoices.\n- Add, edit and delete products.\n- Record customer orders and select order status.\n- Printable invoice in a new browser window.\n- Browser-local persistence using localStorage.\n- Mobile responsive layout.\n\n## Important limitations\nThis is a static front-end prototype, not a production SaaS product. There is no login, secure user account, hosted database, public individual storefront URL, customer checkout, image upload, payment gateway, recurring billing, server-side plan enforcement, email/WhatsApp messaging, tax engine, backup, multi-user access or audit history. Demo sales totals are not verified payments. Do not enter real customer personal or payment information.\n\n## Production architecture required\nRecommended next stage: a maintained frontend framework plus Supabase (PostgreSQL, Auth and Storage), or equivalent. Use tenant-scoped users, businesses, products, customers, orders, order_items, invoices and subscriptions tables. Enforce database row-level security so each business can access only its own records. Store money in integer minor units with explicit ISO currency. Snapshot product names and unit prices into order items so historic invoices do not change when products are edited. Public catalogue routes must expose only active product information, never customer or order records. Verify payment-provider webhook signatures and process events idempotently; never trust a browser-only payment flag. Add privacy policy, terms, data export/deletion, backups, support and cancellation processes before public launch.\n\n## Proposed pricing (unvalidated)\n- Free: up to 10 products, catalogue, manual orders and printable invoices.\n- Starter: $4.99/month.\n- Pro: $9.99/month.\n- Optional one-time template packs and setup services.\nThese are hypotheses for customer testing, not confirmed market prices or active offers.\n\n## Deployment\nStatic prototype: repository root, index.html entry point, no build command. Production SaaS backend is not included.\n
